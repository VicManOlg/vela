# Emulator catalogue schema (`catalog/emulators.json`, schemaVersion 1)

Generated by `scripts/build_emulator_catalog.py`; Kotlin model in
`core/model/.../EmulatorCatalog.kt` (`LaunchCatalog`), loader `core/catalog/.../EmulatorCatalog.kt`.
Regenerate with `python scripts/build_emulator_catalog.py` (network) or `--offline` (uses
`scripts/.cache`). Parser tests: `python -m unittest scripts/test_build_emulator_catalog.py`.

```
{
  "schemaVersion": 1,
  "generatedAt": "YYYY-MM-DD",
  "sources": [ { id, name, url, revision (commit sha), license, copyright } ],
  "platforms": [
    {
      "id": "nes",                    // Daijishō uniqueId; usually equal to Vela's platform id, not guaranteed
      "name": "...", "shortName": "...",
      "extensions": ["nes", "zip"],   // union of the emulators' filters, lowercase, no dot
      "acceptedFilenameRegex": "...", // Daijishō's platform-level filter, verbatim
      "source": "daijishou",
      "emulators": [ <emulator> ]
    }
  ],
  "knownActivities": [ { emulator (ES-DE name), package, activity } ],
  "warnings": [ { platform, emulator, message } ]
}
```

## Emulator

| field | meaning |
|---|---|
| `id`, `name` | Daijishō player `uniqueId` and display name |
| `extensions` | from the player's `acceptedFilenameRegex` |
| `package`, `activity` | from `-n pkg/activity`; relative `.Foo` expanded to `pkg.Foo`; `-p` fills `package` alone |
| `action`, `categories`, `mimeType`, `data` | `-a`, `-c` (repeatable), `-t`, `-d` |
| `dataType` | `uri` / `path` / `both` / `none` — which placeholder kind the recipe uses anywhere |
| `extras` | `[{key, type, value}]`; type from the option: `-e`/`--es` string, `--ez` boolean, `--ei` int, `--el` long, `--ef` float, `--eu` uri, `--ecn` component, `--esa`/`--eia`/`--ela`/`--efa` arrays (comma-separated value), `--esal`… lists, `--esn` null (no value) |
| `flags` | `Intent.FLAG_*` names from `--activity-*` / `--grant-*` options and from a numeric `-f` (decoded bit by bit) |
| `forceStopBeforeLaunch` | `-S` present |
| `killProcess` | Daijishō `killPackageProcesses` |
| `requiresBios` | always `null` today: neither source carries it |
| `placeholders` | every `{...}` token found (`{file.uri}`, `{file.path}`, `{tags.x360url}`, …) |
| `esdeVerified` | `true` if ES-DE's find rules list the same package/activity; `false` if not; `null` if ES-DE was unreachable when generating |
| `source` | `daijishou` |
| `raw` | the original `amStartArguments`, untouched — the ground truth |
| `notes` | Daijishō's description |
| `warnings` | anything the parser did not fully understand for this recipe, plus `unparsed: ...` with the tokens kept verbatim |

## Parser guarantees

- Tokenisation is shell-like (quotes respected, newlines are separators). Unbalanced quotes fall
  back to whitespace splitting with a warning.
- Unknown options and stray tokens are **never dropped**: they land in `warnings` as
  `unknown token` / `unparsed: ...` and the whole command stays in `raw`.
- `am` options that are meaningless for a frontend (`-W`, `-D`, `--user`, `-P`, …) are recorded
  as warnings, not errors.
- A recipe without `-n`/`-p` gets the warning `no package (-n or -p)` and `package = null`.

## Mapping to Vela's `players.json`

`{file.uri}` → `{rom.uri}` with `delivery` `CONTENT_URI_DATA` (when in `-d`) or `EXTRAS_ONLY`
(when in an extra) plus `FLAG_GRANT_READ_URI_PERMISSION`; `{file.path}` → `{rom.path}` with
`requiresFilePath: true`; `--activity-clear-task/-top` → the same `FLAG_ACTIVITY_*` names in
`flags`. Keep `FLAG_ACTIVITY_NEW_TASK`. Put the Daijishō `id` and the source in `notes`.
